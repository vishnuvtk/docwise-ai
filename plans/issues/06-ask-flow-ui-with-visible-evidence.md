## What to build

Complete the user-facing ask flow so a reviewer can load Docwise AI, see the bundled library, ask a question, and inspect either a grounded answer or a refusal together with visible evidence. This slice should make the trust model obvious in the interface rather than hiding it inside server behavior.

## Acceptance criteria

- [ ] The homepage clearly explains the app boundary and shows the bundled document library available for search.
- [ ] Users can submit a single question across the whole library and receive either an answered or refused result through the main UI flow.
- [ ] The result view prominently displays evidence, including citations, excerpts, and file identifiers, with page numbers when available.
